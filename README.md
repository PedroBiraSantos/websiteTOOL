## 🇧🇷 Português

### Sobre o projeto

Este projeto é um website desenvolvido como trabalho acadêmico para apresentar a banda **TOOL**, explorando sua história, discografia, integrantes e identidade visual.

A proposta do site é combinar informações sobre a banda com uma experiência visual inspirada pela estética sombria, orgânica e surreal associada à identidade artística do TOOL.

O projeto foi desenvolvido utilizando apenas **HTML, CSS e JavaScript**, sem frameworks ou bibliotecas externas para a estrutura principal do site.

### Conteúdo

O site possui páginas dedicadas a:

- **Início** — apresentação da banda, vídeo, citações e conteúdo audiovisual.
- **História** — trajetória da banda desde sua formação.
- **Discografia** — principais álbuns de estúdio, informações e tabela.
- **Integrantes** — apresentação dos membros da banda.
- **Fã-clube** — formulário de inscrição para demonstração de validação com JavaScript.
